# AGENTS Instructions

## Mandatory Session Report Rule

At the end of **every** coding session in this repository, the agent must save a session report update.

Required actions before closing a session:

1. Update `docs/SESSION_REPORT.md` with a new dated entry.
2. Include:
   - objectives attempted
   - code/config changes made
   - experiment commands and key metrics
   - best current checkpoint/config recommendation
   - unresolved issues and next actions
3. If no code changed, still add a short entry stating what was inspected and what decision was made.

A session is not complete until the report update is saved.
